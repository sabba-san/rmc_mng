🔌 RMC System API Reference

Authentication

POST /auth/login GET /auth/me

Grants

GET /grants/ POST /grants/ PUT /grants/:id

Milestones

GET /milestones/grant/:id PUT /milestones/:id

Documents

POST /documents/upload GET /documents/download/:id

Base URL: http://127.0.0.1:5000/api

All endpoints (except login) require a Bearer token in the Authorization header: Authorization: Bearer

POST /auth/login

Authenticate a user and receive an access token.

Request Body
{
  "email": "researcher@uum.edu.my",
  "password": "Researcher@123"
}
Response (200 OK)
{
  "access_token": "eyJhbG...",
  "user": {
    "id": 1,
    "name": "Alice",
    "role": "researcher"
  }
}
GET /grants/

List grants based on the user's role. Researchers see their own grants; Admins/Reviewers see all or relevant grants.

Query Parameters
ParameterTypeDescription
statusstringFilter by status (e.g., pending, approved)
Response (200 OK)
[
  {
    "id": 1,
    "title": "AI Drug Discovery",
    "status": "approved",
    "amount_requested": 50000,
    "grant_type": "internal"
  }
]
POST /documents/upload

Upload a secure document linked to a grant. Must be sent as multipart/form-data.

Form Data
KeyTypeDescription
filefileThe physical file (PDF, PNG, etc). Checked via magic bytes.
grant_idintID of the grant
doc_typestringE.g., proposal, receipt, report
Response (201 Created)
{
  "message": "File uploaded securely",
  "document_id": 14
}
